## What it does

Local-only by design: it keeps hands-on work on your own laptop while cloud agents stay the default for anything that ends in a GitHub PR. It runs when you ask it to, rather than on a timer. Keeping the local and cloud roles separate is deliberate: it stops experiments on your laptop leaking into the branch history of real work.

## Before you install

Open the share link and read the instructions it carries before you add it. @ryanthawks shared this one publicly, and adding it copies the setup into your own account rather than giving you access to theirs.
