This is the loop a small team wishes it had: an idea becomes a pull request overnight, an agent iterates until the test passes, and two reviewers — one risk-first, one merge-gate — decide whether it ships, while a gardener quietly removes the dead code nobody gets to. It runs itself and stops at your gate, so you review decisions rather than type every line.
