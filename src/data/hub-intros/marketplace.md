Somebody built a Grok Bot that works, packed the whole thing up, and posted the link. That is what a shareable bot is: instructions, memories and the workflow it runs, copied into your own account in one click, with the personal data stripped out before it ever left their machine. xAI has not opened a public catalogue for these yet, so this one is kept by hand. Every entry here names the person who shared it and links back to the post it came from. Read what a bot actually does before you add it, because those instructions arrive with it, and treat any request for a key or a password as a reason to walk away.
