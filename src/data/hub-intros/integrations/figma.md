Figma is where a Bot can help connect design work to the rest of the project. It can summarize a file, draft implementation notes, prepare copy variants, or pull design context into a GitHub issue. Content-production crews often include a visual role, and engineering teams need clearer design handoffs. This hub is for Figma-connected setups that make the handoff less lossy. Strong entries name the file, frame, comment thread, or component set. The Bot should cite the design source and ask before changing any shared asset.
