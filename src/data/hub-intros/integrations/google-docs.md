Google Docs is where a Bot can draft in the open. It can prepare a brief, update an SOP, write a support article draft, or turn research notes into a document someone can edit. The higher-stakes version starts with a product change that needs a help doc, then drafts from the changed workflow. This hub is for Docs setups that keep revision and review visible. Good entries say what source fed the draft, where comments go, and whether the Bot is allowed to edit the document or only suggest changes.
