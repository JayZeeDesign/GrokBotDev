Zapier is the glue option when a Bot needs to touch a tool without a custom connector. It can pass a new row to Sheets, catch a form submission, send a Slack ping, or create a task after a webhook. Many Bot workflows need one clean handoff between tools, even when Zapier is not the star. This hub is for simple handoffs that are easier to explain than to code. Good entries name the trigger, the zap, the destination, and the payload. The Bot should make the step visible, because hidden glue is hard to debug.
