GitHub is where a Grok Bot can prove its work. It can read issues, inspect commits, draft PR notes, update status pages, or connect a merge to a docs change. Grok Ship makes GitHub central to the software-factory pattern, and smaller workflows show commits turning into issues or PRs triggering Intercom updates. This hub is for repo-connected setups with a visible trail. The best entries show the branch, issue, commit, check, or pull request that caused the Bot to act. If the Bot changes code, review should stay human.
