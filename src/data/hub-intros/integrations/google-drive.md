Google Drive is often the shared floor under a Bot crew: briefs, screenshots, SOPs, exports, and project notes all live there. Shared files matter because per-Bot memory can drift away from the source of truth. A Grok Bot can read a narrow folder, add a report, organize evidence, or keep a project packet current. This hub is for Drive setups where file scope matters. Strong entries name the folder, the file types, the write rule, and the cleanup path. If a Bot can see the whole drive, the setup is probably too broad.
