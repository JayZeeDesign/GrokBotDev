Home Bots work best when they handle one repeatable chore. They can prepare a morning brief, check a delivery, organize a shared note, or help with a household admin task that nobody wants to own. Useful home patterns include family admin, morning surf checks, message triage, and small solo-operator routines. This hub is for domestic systems that are useful without becoming creepy. Strong entries define the boundary: which calendar, which inbox, which room, which list. The Bot should make the next household decision easier, not watch the whole house.
