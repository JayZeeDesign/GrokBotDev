Engineering docs go stale the minute a workflow changes. A Grok Bot can watch merged PRs, decide whether a user-facing page changed, draft the update, and gather screenshots from a test account. The clean version is a docs setup that updates only when the product change calls for it. This hub is for API notes, Intercom articles, runbooks, changelogs, and internal guides. The best entries keep the source code, the screenshot, and the final paragraph tied together, then ask a human before publishing anything customers rely on.
