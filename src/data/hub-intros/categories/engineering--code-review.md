Code review is not just finding bugs. A Grok Bot can read the issue, inspect the diff, ask for missing tests, and write a short risk note before a human merges. Grok Ship uses fresh-context reviewers, and the Compound Engineering plugin turns planning, review, and lessons learned into a loop. This hub is for review setups that keep the Bot inside a clear boundary: comment, propose, test, or block for a human decision. Strong entries show the repo, the trigger, the review checklist, and how the Bot avoids approving its own work.
