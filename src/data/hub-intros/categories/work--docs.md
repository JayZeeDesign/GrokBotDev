Docs are where a Bot can be careful in public. A strong setup watches the source of truth, decides when a page has gone stale, and drafts a clean update with links back to the change. The clearest pattern starts after a merged PR: the Bot checks whether customer-facing docs need work, grabs screenshots, and updates Intercom only when the workflow changed. This hub is for Google Docs, product docs, SOPs, briefs, and handbooks. Favor entries that show the before, the trigger, and the review path, because wrong docs scale confusion.
